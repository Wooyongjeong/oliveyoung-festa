## 에이전트 작업 순서

1. 현재 단계 문서와 `docs/IMPLEMENTATION_PLAN.md`를 읽는다.
2. 구현을 시작할 때 상태를 `진행 중`으로 바꾼다.
3. 구현 및 테스트 후 해당 체크리스트를 갱신한다.
4. `구현 내용`에 실제 변경을, `검증 결과`에 실행한 명령과 결과를 기록한다.
5. 필수 항목이 모두 끝나면 단계와 이 표를 `완료`로 바꾼다.
