# 단계 4 — 점유 만료와 다중 인스턴스 경합

상태: **예정**

## 목표

만료 작업자가 여러 개이거나 결제와 만료가 동시에 실행돼도 재고가 정확히 한 번만 복구되게 한다.

## 체크리스트

- [ ] 결제 미시작 점유의 요청 시 지연 정리
- [ ] `FOR UPDATE SKIP LOCKED` 기반 주기적 만료 작업
- [ ] 점유 종료와 재고·구매 권리 복구의 단일 트랜잭션
- [ ] `PAYMENT_PROCESSING` 점유 만료 제외
- [ ] 결제 성공과 만료 경합 테스트
- [ ] 다중 만료 작업자의 중복 복구 방지 테스트
- [ ] Compose 백엔드 2개 인스턴스 검증
- [ ] 프로세스 재시작 후 만료 복구 검증

## 구현 내용

아직 구현하지 않았다.

## 검증 결과

아직 실행하지 않았다.

## 남은 사항

체크리스트 전체.
