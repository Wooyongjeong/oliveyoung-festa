# 단계 5 — Redis 대기열과 구매 접근 제어

상태: **예정**

## 목표

Redis로 이벤트별 FIFO 진입 순서와 제한된 활성 구매자 슬롯을 관리하되 업무 상태는 PostgreSQL에서 보호한다.

## 체크리스트

- [ ] 사용자·이벤트별 단일 FIFO 대기 항목
- [ ] Redis Lua 기반 원자적 순번·승격 처리
- [ ] 활성 토큰 TTL과 사용자 바인딩
- [ ] 활성 사용자 수와 초당 승격률 설정
- [ ] 매진 시 승격 중단과 재고 복구 후 재개
- [ ] 주문 API의 활성 토큰 검증
- [ ] Redis 유실 후 기존 PostgreSQL 주문 우선 복구
- [ ] 대기 상태와 구매 가능 여부 UI
- [ ] 다중 인스턴스 활성 한도·토큰 탈취·만료 테스트
