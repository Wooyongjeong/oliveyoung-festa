# 단계 2 — 원자적 주문 생성과 재고 점유

상태: **예정**

## 목표

PostgreSQL 트랜잭션과 조건부 갱신으로 초과 판매와 사용자 중복 구매를 막는 주문·점유 기반을 구현한다.

## 체크리스트

- [ ] 주문·점유·구매 권리·상태 이력 스키마와 핵심 제약
- [ ] 서버 기준 가격·통화·이벤트·등급 스냅샷
- [ ] 주문 상태 전이 규칙과 단위 테스트
- [ ] `available > 0` 조건의 원자적 재고 점유
- [ ] 사용자·이벤트별 구매 권리 원자적 선점
- [ ] `Idempotency-Key`와 요청 본문 해시 처리
- [ ] 주문 생성 및 내 주문 조회 API
- [ ] 재고 2매/동시 요청 100건에서 성공 정확히 2건
- [ ] 동일 사용자 동시 요청에서 성공 최대 1건
- [ ] 재고 불변식과 멱등 충돌 테스트
